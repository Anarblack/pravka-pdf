# Правка PDF

Простой редактор PDF прямо в браузере: переписать строку, добавить надпись и фото, закрасить лишнее и скачать готовый файл.

**Открыть:** https://anarblack.github.io/pravka-pdf/

Файлы никуда не загружаются: PDF открывается и собирается на вашем устройстве. После первого открытия приложение работает и без интернета.

## Что умеет

- **Править.** Щёлкните по строке в PDF — она станет редактируемой. Шрифт, жирность, цвет и фон под строкой подбираются сами, их можно поменять.
- **Текст.** Щёлкните по странице и напишите новую надпись. Новая строка — Enter.
- **Фото.** Кнопка «Фото», перетаскивание файла в окно или ⌘V. Двигается мышью или пальцем, размер — за уголок (с Shift — без пропорций).
- **Закрасить.** Проведите рамку поверх того, что нужно скрыть. Цвет берётся с фона вокруг.
- Отмена (⌘Z), масштаб, многостраничные документы, тёмная тема, работа на телефоне.

## Как поставить как приложение

- **Mac, Chrome:** значок установки в адресной строке → «Установить». После этого PDF можно открывать через «Открыть с помощью → Правка PDF».
- **Mac, Safari:** меню «Файл» → «Добавить в Dock».
- **iPhone, Safari:** «Поделиться» → «На экран „Домой“». Готовый PDF сохраняется через меню «Поделиться» → «Сохранить в Файлы».

## Ограничения

- Существующий текст правится так: старая строка закрывается цветом фона, поверх пишется новая. Шрифт подбирается похожий (Roboto, PT Sans, PT Serif, PT Mono), но не всегда тот же самый.
- Если новая строка длиннее старой, она наезжает на соседний текст — место само не раздвигается.
- В сканах текст — это картинка: там работают «Закрасить» и «Текст».
- PDF, защищённые от изменений, сохраняются с правками, но страницы в них становятся картинками.

## Как устроено

Один файл `index.html` без сборщика и зависимостей на сервере:
[pdf.js](https://github.com/mozilla/pdf.js) 3.11.174 показывает страницы и находит строки текста,
[pdf-lib](https://github.com/Hopding/pdf-lib) 1.17.1 и [@pdf-lib/fontkit](https://github.com/Hopding/fontkit) 1.1.1 дописывают правки в исходный PDF.
`sw.js` кэширует всё для работы без сети.
